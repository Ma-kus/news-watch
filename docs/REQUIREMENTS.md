# 需求規格 (Requirements)
使用者:CHIH HUNG WANG,半導體/晶片/AI B2B 科技媒體總編輯。介面語言:繁體中文;時區 Asia/Taipei。

## 1. 目的
快速掌握**當天 08:30 前 24 小時**國際與台灣發生的重要科技新聞,找出報導角度/題材,並作為產業交流的最新談資。

## 2. 使用者原始條件(逐字摘錄)
1. 「全球或台灣重要半導體廠、晶片商、科技大廠(如 Google, APPLE, AMAZON, Microsoft, Meta)、台灣科技業重要上市櫃公司(如 TSMC, MediaTek, ASpeed...等)發布的相關新聞,如產品技術的發布與突破、公司策略布局動態(如購併、合作消息)」
2. 「篩選出來的新聞,要跟台灣產業有重要關連,且會帶來值得台灣產業界關注的重要影響」
3. 「除了廠商新聞外,全球或台灣政府相關重要科技政策,特別是會影響全球或台灣未來科技產業發展的重要政策新聞」
4. 「最後,是會影響科技產業發展的重要政治、經濟或財務變化,例如俄烏戰爭、疫情、通膨等」
- 輸出:當天必讀 20 則;先給一段綜合分析(為何選這 20 則、對全球/台灣科技產業的影響);再列標題(英文外電自動轉譯成中英對照)與超連結。
- 條件須可由使用者自行選擇/補充,不可只限於初始關鍵字,避免漏掉重要新聞。
- 保留所有蒐集到的新聞,供依領域/興趣查詢閱讀。
- 綜合分析需用兩個角色視角:資深 B2B 科技媒體總編輯、科技公司 CEO/COO。
